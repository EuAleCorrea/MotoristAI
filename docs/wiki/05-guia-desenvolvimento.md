# 💻 Guia de Desenvolvimento

## 🎨 Regras de UI/UX
*   **Bordas**: Usar `rounded-[2rem]` para cards grandes e `rounded-xl` para botões/inputs.
*   **Inputs**: Impedir spinners em inputs de tipo numérico.

## 🚀 Processo de Deploy
*   Gerar saída standalone no `next.config.ts`.
*   Usar build configurado no `nixpacks.toml`.
